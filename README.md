# Centro de Atividades Sesc Palmas

Tour virtual: https://mgtour360graus.github.io/centro-de-atividades-palmas/

Exportação 3DVista com interface independente em `skin-palmas/`. A navegação organiza 187 panorâmicas em 45 ambientes e oito categorias. Títulos e subtítulos distinguem as salas da Educação Infantil e da Escola Sesc. O menu inclui o endereço do Google Maps fornecido para a unidade.

Os arquivos gerados do player, bibliotecas, idiomas, mídias, áudio e hotspots foram preservados. O arquivo de entrada carrega os controles adicionais, com navegação pela playlist nativa. `index.html` permite acessar o tour pela raiz do GitHub Pages; `index.htm` continua disponível.

Validação local: Chrome e Edge no Windows, 15 larguras entre 320 e 1920 pixels, navegação das oito categorias, pesquisa, galeria, som e fechamento de painéis. Emulação móvel e tablet não substitui validação em iPhone/iPad físico ou Safari. A interface evita filtros e transformações sobre o player e mantém o som sob controle do visitante.
