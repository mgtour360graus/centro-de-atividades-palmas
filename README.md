# Centro de Atividades Sesc Palmas

Tour virtual 360° com exportação nativa do 3DVista e interface externa.

A revisão de 9 de novembro de 2026 reúne Educação Infantil e Escola Sesc em Educação, organiza os serviços em Geral, Entrada, Educação, Saúde, Cultura, Lazer/Esporte, Assistência e Alimentação, e utiliza a marca Sesc Fecomércio Senac fornecida para a revisão.

A barra de categorias no celular se oculta durante o arraste do panorama e retorna 420 ms após o término do gesto. As adaptações da interface são carregadas pelo `index.htm`; os arquivos internos do player permanecem como saíram do 3DVista.
